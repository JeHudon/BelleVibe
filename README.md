# BelleVibe

---

## Lancer le projet

### 1. Installer les dépendances

Exécuter `npm install` dans chacun des dossiers suivants :

```
BelleVibe\Code - BelleVibe
BelleVibe\Code - BelleVibe\FrontEnd
BelleVibe\Code - BelleVibe\BackEnd
```

### 2. Démarrer le serveur de développement

Depuis le dossier `BelleVibe\Code - BelleVibe`, lancer :

```
npm run dev
```

Cela démarre le **BackEnd** et le **FrontEnd** simultanément.
